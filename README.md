# Delightful

A food and farming content mod for the [Horizon](https://github.com/horizon-rust/horizon) Minecraft client: a clone of
Farmer's Delight and seven add-ons, reusing their assets only where their licences allow.

Delightful is **content (`.hmod`) with no code**, plus a small native mod for its add-on settings menu. Its machines (the cooking pot and others) are data files for
[Cookpot](https://github.com/realblobii/cookpot), the library mod that provides the crafting-machine engine.

## Status

First increment generated (2 Nov 2026): five content mods and an add-on settings page. **Nothing has been run in Horizon yet.**

## Requirements

- Horizon (a nightly that matches the Cookpot pin).
- [Cookpot](https://github.com/realblobii/cookpot), installed as a native mod.
