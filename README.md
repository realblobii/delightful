# Delightful

A food and farming content mod for the [Horizon](https://github.com/horizon-rust/horizon) Minecraft client: a clone of
Farmer's Delight and its main add-ons, reusing their assets only where their licences allow.

Delightful is a **content mod (`.hmod`) with no code**. Its machines (the cooking pot and others) are data files for
[Cookpot](https://github.com/realblobii/cookpot), the library mod that provides the crafting-machine engine.

## Status

Planning. This repository holds the brief and instructions only; nothing is built, and nothing has been run in the game.

## Requirements

- Horizon (a nightly that matches the Cookpot pin).
- [Cookpot](https://github.com/realblobii/cookpot), installed as a native mod.
