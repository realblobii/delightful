# Delightful

A food and farming content mod for the [Horizon](https://github.com/horizon-rust/horizon) Minecraft client, in the
spirit of Farmer's Delight. It is an **original** mod: its own names, art, sounds and recipes.

Delightful is a **content mod (`.hmod`) with no code**. Its machines (the cooking pot and others) are data files for
[Cookpot](https://github.com/realblobii/cookpot), the library mod that provides the crafting-machine engine.

## Status

Just started. This repository only holds instructions so far; the feature list is still to come. Nothing here has been
built or run in the game.

## Requirements

- Horizon (a nightly that matches the Cookpot pin).
- [Cookpot](https://github.com/realblobii/cookpot), installed as a native mod.
