# Credits and licences

Delightful's content is carried from these MIT-licensed projects; their licence texts are in `licenses/` and each content
mod folder holds its own copy. Textures, models, sounds, text and recipes come from them unchanged except for format upgrades.

| Mod | Author(s) (from the licence) | Source |
|---|---|---|
| Farmer's Delight | vectorwing | https://github.com/vectorwing/FarmersDelight |
| Rustic Delight | PhantomWing | https://github.com/PhantomWing/RusticDelight |
| Expanded Delight | ianm1647 | https://github.com/ianm1647/expandeddelight |
| Corn Delight | Zheng Syameimaru | https://github.com/0999312/Corn-Delight |

**To confirm:** the repositories carry an MIT licence for the code. None stated a separate licence for artwork, but a mod's
art may still belong to its artists: if an author objects, the content is removed. Expanded Delight ships no
`LICENSE` file at the root of its repository (its `gradle.properties` says MIT); see `licenses/NOTICE-expandeddelight.txt`.
